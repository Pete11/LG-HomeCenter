# LG Home Center v0.6.1

Patch release for LG webOS TV 25 / Homebrew Channel.

This update improves Magic Remote directional navigation, installed-app selection readability, retrieval and display of original app icons, and application launching through the Homebrew root command bridge with webOS API fallback.

See `README_RO.md` for repository update instructions and `docs/RELEASE_NOTES_v0.6.1.md` for details.

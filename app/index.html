Use LG Home Center for the remote HOME button

Home Center declares itself as a webOS Home app. Home Chooser is the supported way to assign the physical HOME button without replacing LG system files.

Home Chooser status has not been checked.
  1. Install Home Chooser from Homebrew Channel and open it once to complete its setup.
  2. Then install or update LG Home Center 0.8.0. This version requests the Home Chooser launcher permission.
  3. Open Home Chooser, select LG Home Center, press OK and confirm.
  4. Press the physical HOME button to test. To restore the original interface, open Home Chooser and select LG Home (stock).

Home Chooser and root-enabled Homebrew Channel are required. Home Center does not change the HOME assignment automatically and does not overwrite LG system files.

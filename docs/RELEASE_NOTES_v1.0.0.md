# Release notes — v1.0.0

## Added
- Added all 37 user-supplied movie wallpaper JPGs to the offline Movies collection.
- Added per-image 480×270 JPEG thumbnails for quicker gallery rendering.
- Added a Movies category and collection-specific slideshow mode.
- Added slideshow sources for Movies, Nature, cinematic originals, all bundled images, prior TV imports, or all sources.
- Added clear guidance for expanding the packaged library from a PC and publishing a new IPK.

## Changed
- Default wallpaper gallery category is Movies.
- New installations default the slideshow source to Movies.
- Existing inactive default Personal slideshow preference is migrated to Movies; active or explicitly enabled settings are retained.
- The unsupported TV file-picker card is replaced with instructions for adding images to the PC project and republishing.

## Compatibility
- Existing app ID and Homebrew repository URL are unchanged.
- Existing local preferences and any prior IndexedDB imports are retained.
- Bundled wallpaper paths are local to the app package.
